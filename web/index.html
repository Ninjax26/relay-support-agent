Inside an investigation

  1. Retrieve

    Search playbooks using BM25 lexical ranking. Relevant documents become evidence.

  2. Investigate

    The live model records a checklist, chooses scoped read tools, and revises its plan after observations.

  3. Propose

    Check the draft against evidence requirements. Fix failed checks before saving the reply and proposal.

  4. Review

    You approve or reject. Approval creates one local review ticket; it does not issue a refund or change an account.

Demo mode uses a deterministic planner. Live mode uses an LLM. Both share the same tools and approval boundary.
